# Announcing The Help App

Today we're introducing the Help App, a dedicated place to find help with the Origami Systems Stack.

Whether you're setting up your account, managing house points, or creating a signup form, the Help App brings instructions together in one place. You can read the guides without signing in.

## Find the help you need

The Help App includes:

- Getting started guides
- Account and security documentation
- Guides for The House App and The Signups App
- Answers to frequently asked questions
- Troubleshooting for common problems
- A contact form for reaching support

Search across the documentation to find a specific topic, or browse by app. When you're viewing an app's help section, search focuses on guides for that app.

## More apps coming soon

As the Origami Systems Stack grows, we'll add guides and support for more apps to the Help App. Check back here for help with new apps as they become available.

## Available now

Visit [help.origamisystems.org to explore the guides](https://help.origamisystems.org).

If you need more help, use [Contact support](https://help.origamisystems.org/contact). Include the app, the page, what you tried, and any error message so we can help you resolve the problem.
