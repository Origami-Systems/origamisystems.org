# A New Look with UI v7

The Origami Systems apps share one interface library, so buttons, forms, and menus look and work the same everywhere. Version 7 of that library is now rolling out, starting with The Signups App and the Account App.

## What's different

- Form fields have labels beside them on larger screens and above them on phones.
- Descriptions and error messages sit next to the setting they belong to.
- Pages show a preview of their layout while they load, so you can see what's coming instead of an empty card.
- When something fails to load, you'll see what went wrong and a way to try again.
- Tags and badges keep their color in both light and dark themes.
- If a save fails, your changes stay in the form so you can try again without retyping them.

## Coming to more apps

More apps will move to UI v7 over the coming weeks. We'll keep improving it as they do.

If something looks wrong or is harder to use after the update, let us know through the [contact form](https://help.origamisystems.org/contact). Include the app, the page, and a screenshot if you can.
